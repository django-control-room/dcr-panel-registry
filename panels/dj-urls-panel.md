Browse every registered URL pattern, namespace, and view in your Django project. Search, filter, and reverse-lookup routes without touching the terminal.

This package includes a url testing interface that allows you to send requests to your app's routes similarly to a swagger based UI. It can also
detect Django Rest Framework based routes and surface information about serializers.
